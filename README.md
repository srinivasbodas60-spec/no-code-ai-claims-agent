# No-Code Claims Intake & Routing Agent

A recruiter-focused blueprint for a human-in-the-loop AI agent that turns unstructured insurance claim requests into structured, traceable work items.

> Portfolio project using synthetic examples. It documents a production-minded design for Microsoft Copilot Studio and Power Automate; it does not contain employer or customer data.

## What it demonstrates

- Copilot Studio conversation topics and structured intake
- Power Automate routing by confidence and urgency
- Dataverse or SharePoint case records and audit events
- Power BI operations metrics
- Human handoff for low-confidence or high-risk requests
- Synthetic evaluation cases and acceptance criteria

The agent can clarify missing details, classify request type, route work, and log decisions. It never approves or denies a claim or authorizes payment.

See the solution blueprint, evaluation plan, topic configuration, and synthetic test cases in this repository.
